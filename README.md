# Chronotext

Chronotext — это NLP-проект для определения примерного времени написания текста.

Главная идея проекта заключается не в том, чтобы определить дату написания конкретной известной книги, а в том, чтобы по самому тексту — его словам, стилю, лексике и языковым особенностям — предсказать, к какому историческому периоду он ближе.

Например, модель должна уметь отличать текст, написанный в стиле XVII века, от текста XIX или XX века, даже если это не произведение из обучающего датасета.

## Цель проекта

Цель проекта — исследовать, можно ли по тексту автоматически определить примерную дату его написания.

На текущем этапе задача рассматривается как классификация текста по историческим периодам:

* `1600`
* `1700`
* `1800`
* `1900`

Каждый класс обозначает примерный век или исторический период, к которому относится текст.

В будущем задачу можно развить в сторону регрессии, где модель будет предсказывать не класс века, а примерный год написания текста.

## Идея

Язык меняется со временем. В текстах разных эпох могут отличаться:

* словарный запас;
* частотность отдельных слов;
* грамматические конструкции;
* стиль повествования;
* длина предложений;
* употребление устаревших слов и выражений.

Chronotext пытается использовать эти признаки, чтобы определить, к какому историческому периоду относится неизвестный текст.

## Данные

В папке `data/` находятся тексты литературных произведений, относящихся к разным историческим периодам.

Название каждого файла содержит примерную дату или век написания текста. Например:

```text
hamlet_1600.txt
pride_and_prejudice_1800.txt
a_room_with_a_view_1900.txt
```

Эти даты используются как метки классов для обучения модели.

## Текущий подход

В первой baseline-версии используется классический подход машинного обучения для работы с текстом:

1. Тексты загружаются из папки `data/`.
2. Для каждого текста определяется исторический класс.
3. Текст преобразуется в числовые признаки с помощью `TfidfVectorizer`.
4. Для классификации используется `LogisticRegression`.
5. Качество модели оценивается с помощью `classification_report`.

После запуска модель обучится на текстах из папки `data/` и выведет отчёт о качестве классификации.

## Особенности задачи

Задача определения даты написания текста отличается от обычной классификации тем, что классы имеют естественный порядок.

Например, ошибка между `1600` и `1700` менее серьёзна, чем ошибка между `1600` и `1900`.

Поэтому в будущем для оценки качества модели можно использовать не только accuracy, precision и recall, но и среднюю ошибку во времени. Например, насколько далеко предсказанный век находится от настоящего.

## Ограничения текущей версии

Текущая версия проекта является baseline-решением и имеет несколько ограничений:

* датасет пока небольшой;
* модель может частично учиться отличать авторов или жанры, а не только эпоху написания;
* классы представлены как отдельные категории, хотя историческое развитие языка является непрерывным;
* тексты относятся в основном к литературным произведениям, поэтому модель может хуже работать на других типах текстов.

## Возможные улучшения

В дальнейшем проект можно развивать в нескольких направлениях:

* увеличить датасет;
* добавить больше текстов разных жанров;
* делить большие произведения на небольшие фрагменты;
* проверять модель на текстах, которых не было в обучении;
* использовать не только классификацию, но и регрессию для предсказания примерного года;
* добавить confusion matrix;
* добавить метрику средней ошибки в годах;
* попробовать более сложные модели, например SVM, Random Forest или нейросетевые модели;
* анализировать, какие слова и признаки сильнее всего влияют на предсказание.

## Главная идея проекта

Chronotext — это попытка научить модель определять время написания текста по самому языку.

Иными словами, проект отвечает на вопрос:

> Можно ли по стилю, словам и структуре текста понять, в какую эпоху он был написан?

Текущая версия — это первый baseline, который проверяет эту идею на литературных текстах разных веков.
